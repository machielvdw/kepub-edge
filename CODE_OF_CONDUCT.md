# Code of conduct

Treat contributors and users respectfully. Discuss ideas and code without
personal attacks. Welcome questions and constructive criticism; assume good
intent and respond thoughtfully when someone explains an impact.

Harassment, discriminatory language, threats, sexualized conduct, doxxing, and
deliberate disruption are not acceptable in project issues, pull requests, or
other project spaces.

The maintainer, [@machielvdw](https://github.com/machielvdw), may edit or remove
content, close discussions, or restrict participation to protect contributors.
Responses should be proportionate to the behavior and its impact.

Report conduct concerns to the maintainer through an existing private contact
channel. If you do not have one, open an issue requesting a private contact route
without naming the people involved or including sensitive details. Avoid sharing
personal information publicly. Security vulnerabilities have a separate
[private reporting channel](SECURITY.md).
